# LogViewer Core

## Overview

LogViewer Core is the free base edition of LogViewer.

Core provides the main functionality for viewing, searching, filtering, monitoring, analyzing, and reporting on real Linux log data.

Core does not require a Pro license.

## Log Viewing

LogViewer can display parsed events from supported Linux log sources.

Events can contain information such as:

- Timestamp
- Source
- Severity
- Message
- Event type
- Host
- User
- Network information
- Process information
- File information
- Security signatures
- Raw event data

## Log Search

Search allows analysts to locate relevant events within available log data.

Search can reduce a large collection of events to activity relevant to an investigation.

## Log Filtering

Filtering narrows events using available event characteristics.

Filters can help isolate activity associated with:

- Sources
- Severity
- Event types
- Hosts
- Users
- Network indicators
- Security events

## Live Monitoring

Live monitoring allows supported log sources to be observed as new events are generated.

## Statistics

Statistics provide an overview of available log activity.

They can help identify:

- Event volume
- Source activity
- Severity distribution
- Security-event patterns

## Report Export

Core provides report-export functionality for supported analysis results.

## Log Source Discovery

LogViewer can discover supported sources available on the Linux host.

Potential sources include:

    /var/log/auth.log
    /var/log/syslog
    /var/log/kern.log
    /var/log/ufw.log
    /var/log/cron.log
    /var/log/apt/
    /var/log/apache2/
    /var/log/nginx/
    /var/log/caddy/
    /var/log/postgresql/
    /var/log/snort/
    systemd journal

The actual sources depend on the host configuration.

## Snort Alert Summary

Core supports Snort alert-summary functionality for supported Snort output.

Available information depends on the Snort version and logging configuration.

## IOC Extraction

LogViewer can extract supported indicators of compromise from events.

Possible indicators include:

- IP addresses
- Domains
- URLs
- File paths
- Hash values

IOC extraction identifies potentially useful indicators. It does not independently prove malicious activity.

## Security Correlation

Security correlation connects related activity across events.

Correlation can help analysts identify relationships that are difficult to recognize from individual events.

## Security Analysis

Security analysis provides structured analysis derived from available log evidence.

Analysts should review the underlying evidence instead of treating automated analysis as absolute proof.

## Application Settings

Supported application settings include:

- Log directory
- Export directory
- Theme
- Logging level

## License Management

Core includes the license-management interface.

Core functionality itself does not require Pro entitlement.

## Data Model

LogViewer is designed around real Linux host data.

The available information depends on the actual logs generated by the host.
