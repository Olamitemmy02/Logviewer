## Product Structure

LogViewer is distributed as two release tracks:

### Core

LogViewer Core is the free distribution.

Core does not require a license and provides the basic Linux log investigation capabilities.

### Pro

LogViewer Pro is the licensed distribution.

Pro extends Core with structured investigation and advanced analysis capabilities. Pro features are controlled by the application's signed license entitlement system.
