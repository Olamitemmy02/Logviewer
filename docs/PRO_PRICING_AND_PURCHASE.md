## What Each Pro Feature Does

### 1. Investigation

**Feature ID: `investigation`**

Price value: **₦15,000**

The Investigation feature provides the main structured security investigation workspace.

It allows related security events and analysis results to be organized into an investigation.

An investigation can contain:

- Events
- Evidence
- Indicators of compromise
- Correlations
- MITRE ATT&CK mappings
- Threat scoring
- False-positive analysis
- Process relationships
- Attack-chain information
- Timeline information
- Investigation findings

The purpose is to give an analyst one structured place to examine a security incident instead of treating every log entry as an isolated record.

### 2. Threat Scoring

**Feature ID: `threat_scoring`**

Price value: **₦8,000**

Threat Scoring evaluates available investigation evidence and produces a threat score and threat level.

The score is an analytical aid.

It does not automatically prove that an activity is malicious.

Analysts should review the score together with the underlying events and evidence.

### 3. MITRE ATT&CK Mapping

**Feature ID: `mitre`**

Price value: **₦10,000**

MITRE ATT&CK Mapping associates relevant investigation activity with applicable MITRE ATT&CK techniques.

This helps an analyst understand how observed activity may correspond to known attacker techniques.

A mapping does not by itself prove that a technique was successfully executed.

### 4. False-Positive Analysis

**Feature ID: `false_positive_analysis`**

Price value: **₦8,000**

False-Positive Analysis examines activity that may have legitimate or non-malicious explanations.

This helps investigators consider alternative explanations before treating activity as malicious.

The feature provides analytical context rather than automatically declaring an event harmless or malicious.

### 5. Process Tree Analysis

**Feature ID: `process_tree`**

Price value: **₦10,000**

Process Tree Analysis builds relationships between processes using available process and parent-process information.

It helps an investigator understand relationships such as:

- Which process started another process
- Parent-child process relationships
- Related process activity
- Process relationships associated with investigated events

The usefulness of the process tree depends on the process information available in the collected logs.

### 6. Attack-Chain Reconstruction

**Feature ID: `attack_chain`**

Price value: **₦12,000**

Attack-Chain Reconstruction organizes related investigation activity into an ordered representation of an attack chain when sufficient evidence exists.

This can help an analyst understand how separate events may relate to one another across an investigation.

The reconstructed chain is an analytical representation and should always be checked against the underlying evidence.

### 7. Investigation Timeline

**Feature ID: `timeline`**

Price value: **₦8,000**

Investigation Timeline organizes relevant investigation activity chronologically.

It can include:

- Events
- Correlations
- MITRE mappings
- Process relationships
- Attack-chain steps
- Timeline gaps
- Confidence information

This helps an analyst understand the sequence and timing of activity.

### 8. Investigation Findings

**Feature ID: `findings`**

Price value: **₦10,000**

Investigation Findings produces structured findings from available investigation evidence and analysis.

Findings can include:

- Finding title
- Summary
- Severity
- Confidence
- Rationale
- Supporting events
- Evidence references
- IOC values
- MITRE techniques
- Correlation information
- False-positive context

Findings are intended to make investigation conclusions easier to review and document.

## Additional Pro Capabilities

### Investigation Reporting

Price value: **₦10,000**

Investigation Reporting produces structured investigation reports.

Supported formats include:

- Markdown
- JSON

Markdown reports are useful for human-readable investigation documentation.

JSON reports provide structured information suitable for processing and archival.

### Evidence Packages and Verification

Price value: **₦12,000**

Evidence Packages allow an investigation report and structured investigation data to be packaged together.

A standard package contains:

    report.md
    report.json
    manifest.json

The manifest contains integrity information for the package files.

Evidence verification checks:

- Required files
- Package paths
- Recorded file sizes
- SHA-256 integrity hashes
- Manifest consistency

A successfully verified package means the package contents match the integrity information recorded in its manifest.
